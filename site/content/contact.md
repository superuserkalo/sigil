Sigil is a free fan project built in the open. There is no company behind it and no support desk, so the place to reach the project is its GitHub repository.

## Report a bug

Open an issue at [github.com/superuserkalo/sigil/issues](https://github.com/superuserkalo/sigil/issues). It helps to say which Sigil version you run (Settings shows it), what you did, what you expected and what happened. If a mod is involved, add its GameBanana link.

Inside the app, Settings has a "Send diagnostics" action. It sends a scrubbed report only when you press it, and never on its own.

## Ask a question or suggest a change

Questions and ideas go to the same issues page. Check the [questions and answers](/faq) first: it covers cost, safety, updates, the Windows warning and uninstalling.

## Security problems

If you find a security problem, such as a way for a mod or a download to do something it should not, please do not post the details in public. Open an issue that only says you have a security report, and you will get a private way to send it.

## Mods and their creators

Sigil does not host mods. Every mod comes from GameBanana and belongs to its creator, so questions about a specific mod are best asked on that mod's GameBanana page.
