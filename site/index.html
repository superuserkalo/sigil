Download

Install Deadlock mods and keep them working.

Sigil is a free, open-source Deadlock mod manager for Windows.

Download for WindowsView on GitHub

Windows 10 and 11, 64-bit. Free and open source. No administrator rights needed.

Windows may show “Windows protected your PC” because the installer is not code signed yet. Choose More info, then Run anyway.

Find the mod you mean

Browse GameBanana inside Sigil and install with one press. Search runs on your PC, forgives typos and knows what a mod is based on, so a series name finds skins whose title never mentions it. What you type is not sent anywhere.

More about browsing and search

See what is on and which mod wins

New installs land switched off until you turn them on. Sigil keeps the load order in view, flags mods that replace the same files and shows which one the game will use.

More about managing installed mods

Launch modded or vanilla

Launch modded checks your mods first and fixes gameinfo.gi when a game update reset it. Launch vanilla puts your mods aside for a clean game and brings them back afterwards.

More about launching

Tune your crosshair at true scale

Set lines, gap, dot and colour over a game scene, then apply it to your autoexec with a backup kept. The community library has crosshairs other players shared.

How it keeps your game working

Checks before it installs

Sigil lists the files in an archive before writing them, and says so when a mod contains programs or scripts.

Waits for the game

While Deadlock runs, turning off or deleting a mod waits until the game closes.

Keeps a way back

Deleted mods go to Sigil's trash with Undo, and gameinfo.gi is backed up before every fix.

Asks before it shares

Nothing about you leaves your PC without your yes. No account, and no third-party analytics in the app.

Questions

Is Sigil free?

Yes. Sigil is free and open source under the MIT licence, and the code is on GitHub.

Is it safe? Can mods get me banned?

Sigil puts mod files in the game's addons folder, the same place a manual install does, and edits gameinfo.gi so the game reads that folder, keeping a backup first. It cannot speak for how Valve treats mods. Launch vanilla starts the game with your mods set aside.

Where do the mods come from?

From GameBanana. Sigil browses and downloads them from there, and every mod belongs to its creator.

My mods stopped working after a Deadlock update. What now?

A game update or a Steam file check resets gameinfo.gi, so the game stops loading your mods. Sigil shows a banner with a Fix button. Mods made for an older build may also need an update from their creator; the guide Deadlock mods not working after an update explains both cases.

Does it work on Mac, Linux or Steam Deck?

The download on this site is for Windows 10 and 11, 64-bit. There is no Mac, Linux or Steam Deck release here.

Why does Windows warn me when I run the installer?

The installer is not code signed yet, so Windows may show "Windows protected your PC". Choose More info, then Run anyway.

What does Sigil send over the internet?

It talks to GameBanana for mods and, if you allow it, to GitHub for app updates. Usage events, crash reports and product data are each off until you agree, and there is no third-party analytics. The privacy page lists every host.
